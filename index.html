How to Update Your Portfolio

Everything on this site is driven by a single, clean file: js/config.js. You do NOT need to write any complex code.

1. Paste Your Links & Profiles Open js/config.js and update your GitHub, LinkedIn, Twitter, and LeetCode URLs inside the socials: { ... } section.
2. Add or Edit Projects Inside js/config.js, find the projects: [ ... ] array. Replace the titles, descriptions, live demo links, and GitHub repository links with your own work.
3. Paste Achievements & Certifications Find achievements: [ ... ] in js/config.js. Add your hackathon wins, coding contest ranks, and course credentials with verification links.
4. Replace Resume PDF Drop your real PDF into the assets/ folder and name it resume.pdf (or paste a Google Drive link in config.js).
5. Free 1-Click Hosting Because this is a 100% static site, you can host it for free on GitHub Pages, Vercel, or Netlify in under 60 seconds. Simply push this folder to a GitHub repo!
